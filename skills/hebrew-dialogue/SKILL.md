# Hebrew Dialogue Skill

Пользователь описывает по-русски бытовую ситуацию и задачу внутри неё. Скилл собирает диалог на иврите **из слов, которые уже есть в его базе**, чтобы он мог проговорить ситуацию заранее.

Отличие от `hebrew-anki-export`: тот принимает **список слов от учителя** и делает карточки. Этот принимает **ситуацию** и делает диалог. Если в сообщении список слов вида `מילה = ПЕРЕВОД` — это не сюда.

---

## Шаг 1 — Загрузить базу

Источник — публичный репозиторий на GitHub:

```
https://raw.githubusercontent.com/AndreyLevitskiy/hebrew-anki-words/main/hebrew_words.json
```

Качать в песочницу через `bash`, один раз за разговор:

```bash
test -f /home/claude/hebrew_words.json || curl -sSf \
  "https://raw.githubusercontent.com/AndreyLevitskiy/hebrew-anki-words/main/hebrew_words.json" \
  -o /home/claude/hebrew_words.json
python3 -c "import json;d=json.load(open('/home/claude/hebrew_words.json'));print(sum(len(v) for v in d.values()),'слов')"
```

Файл ~130 КБ — в контекст целиком не тянуть и глазами не читать, работать только кодом по локальной копии. Песочница живёт один разговор; в новом чате качать заново.

Домен `raw.githubusercontent.com` в песочнице доступен, авторизация не нужна — репозиторий публичный. Работает с любого устройства, включая телефон.

**Свежесть.** GitHub отдаёт raw через CDN с кэшем в несколько минут. Если пользователь только что пополнил базу и новых слов не видно — добить кэш параметром: `...hebrew_words.json?t=$(date +%s)`.

**Если не скачалось.** Проверить, что репозиторий на месте и публичный (`curl -sI` на ту же ссылку). Сказать пользователю прямо и попросить приложить `hebrew_words.json` к сообщению файлом. **Не выдумывать диалог по памяти** — смысл скилла в том, что слова взяты из реальной базы.

### Структура базы

```json
{
  "מילים":        [{"hebrew": "אבטיח", "russian": "арбуз"}],
  "פעל מילים":    [{"hebrew": "לפחד",  "russian": "бояться"}],
  "פיעל מילים":   [{"hebrew": "לאחר",  "russian": "опаздывать"}],
  "הפיעל מילים":  [{"hebrew": "להגיע", "russian": "прибывать"}],
  "התפעל מילים":  [{"hebrew": "להתאמץ","russian": "стараться"}],
  "נפעל מילים":   [{"hebrew": "לגשת",  "russian": "подходить"}]
}
```

Шесть секций по биньянам. Глаголы хранятся **в инфинитиве, без никуда и без спряжений** — спрягать надо самому. Существительные и прилагательные — в `מילים`, часто в форме м.р. ед.ч. или парой через слэш (`מעסיק / מעסיקה`).

**Битые записи.** В базе есть записи, где внутрь ивритского слова затесалась кириллическая буква (`להכיн`, `ליצг`, `נהг`) — следы опечаток при вводе. Такое слово нельзя вставлять в диалог как есть. Отсеивать на этапе подбора:

```python
import re
CYR = re.compile(r"[а-яА-ЯёЁ]")
def broken(w): return bool(CYR.search(w["hebrew"]))
```

Если нужное по смыслу слово оказалось битым — либо восстановить очевидную опечатку самому (`להכיн` → `להכין`) и пометить как исправленное, либо взять синоним. Не молчать об этом: коротко сказать, какие записи в базе стоит починить.

**Известь ≠ база в чистом виде.** Кроме слов из JSON разрешено свободно использовать служебную лексику, которую человек этого уровня знает по определению и которой в базе может не быть: местоимения, `יש/אין`, `זה`, предлоги (`של`, `עם`, `בשביל`, `על`, `ב-`, `ל-`, `מ-`), числительные, `כן/לא`, `בבקשה`, `תודה`, `סליחה`, дни недели, базовые глаголы `להיות`, `לרצות`, `לצריך`, `יכול`. Всё остальное — только из базы.

## Шаг 2 — Понять задачу

Из реплики пользователя вытащить:
- **место / собеседника** (врач, курьер, банк, автосервис, садик);
- **его коммуникативную цель** — что он хочет сообщить или получить;
- **кто он в диалоге** (обычно — он сам, «клиент»).

Если ситуация описана внятно — **не переспрашивать**, сразу собирать. Уточняющий вопрос уместен только если непонятна сама цель («поговорить с врачом» — о чём?).

---

## Шаг 3 — Подобрать слова

Прогнать базу кодом и достать кандидатов по теме. Практичный приём: искать по **русскому** полю, оно точнее ловит тему, чем иврит.

```python
import json, re
db = json.load(open("/home/claude/hebrew_words.json", encoding="utf-8"))
CYR = re.compile(r"[а-яА-ЯёЁ]")
words = [(s, e["hebrew"], e["russian"])
         for s, arr in db.items() for e in arr
         if not CYR.search(e["hebrew"])]          # битые записи отсеяны
pat = re.compile("боль|врач|нога|рука|болезн|лекарств|температур", re.I)
hits = [w for w in words if pat.search(w[2])]
```

Ключевые слова паттерна подбирать под ситуацию, брать с запасом и синонимами. Затем глазами отобрать те, что реально лягут в диалог. Учесть, что поиск по подстроке шумит: `боль` цепляет `רוב` («большинство»).

**Проверка перед сборкой:** каждое содержательное слово будущего диалога должно найтись в `words`. Не «кажется, он это знает» — а буквально проверено кодом.

---

## Шаг 4 — Собрать диалог

6–10 реплик, чередование «собеседник ↔ пользователь». Реплики короткие, как в жизни, без книжных оборотов.

Формат каждой реплики — три строки:

```
👨‍⚕️ מה כואב לך?
   ма коэ́в леха́?
   Что у вас болит?

🙋 כּוֹאֶבֶת לִי הָרֶגֶל כְּבָר שָׁבוּעַ.
   коэ́вет ли ѓа-ре́гель квар шаву́а.
   Нога болит уже неделю.
```

- иврит **с никудом** — реплики пользователя обязательно, реплики собеседника можно без;
- транслитерация русскими буквами — цель проговорить, а не прочитать;
- перевод.

Ударение в транслитерации отмечать `́` на гласной. `ה` в начале артикля — `ѓа-`.

**Слова не из базы.** Если без слова диалог не собирается — вставить, но пометить `*` прямо в строке перевода и вынести в конец (см. шаг 5). Не больше 3–4 таких на диалог; если их нужно десять — значит, тема пользователю пока не по словарю, честно сказать это и предложить более простой вариант той же ситуации.

**Грамматика.** Спрягать глаголы по лицу и времени самому. Пользователь — мужской род (`אני רוצה`, `כואב לי`). Собеседник — по контексту.

---

## Шаг 5 — Хвост ответа

После диалога дать три блока, коротко:

1. **Если пойдёт не по плану** — 3–4 фразы, которые собеседник реально может сказать в ответ, чтобы пользователь узнал их на слух (`יש לך תור?`, `תמלא את הטופס`, `תחכה רגע`).
2. **Слова не из базы** — списком в формате, готовом для `hebrew-anki-export`:
   ```
   כאב = БОЛЬ
   להתלונן – התלונן – מתלונן – יתלונן = ЖАЛОВАТЬСЯ
   ```
   Так их можно одним движением отправить в карточки.
3. **Предложить отыграть** — «могу сыграть врача, отвечай сам, поправлю». Если пользователь соглашается — вести диалог по одной реплике, ждать его ответа, мягко исправлять: сначала что он сказал верно, потом как звучит естественнее. Не сваливать разбор в конец, поправлять по ходу.

---

## Чего не делать

- Не давать таблицы спряжений и грамматические лекции, если не просили. Цель — проговорить ситуацию, а не разобрать биньян.
- Не усложнять. Короткая фраза, которую он скажет, лучше правильной, которую забудет.
- Не выдавать диалог без чтения базы.
- Не трогать `hebrew_words.json` — этот скилл только читает. Пишет в базу только `hebrew-anki-export`, локально на Маке, и сам пушит изменения в GitHub.
